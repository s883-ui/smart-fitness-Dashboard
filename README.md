# Smart Fitness & Nutrition — Dashboard

شرح كامل للمشروع من الصفر: الملفات، والربط بينها، وكل جزء بيعمل إيه.

---

## 1. شكل المشروع

```
sfn-dashboard/
├── index.html          ← الهيكل، وده الملف اللي بتفتحه
├── README.md           ← الملف ده
├── css/
│   └── style.css       ← كل الشكل والألوان
├── js/
│   ├── data.js         ← البيانات والـ State
│   ├── components.js   ← القطع اللي بتتكرر + الـ charts
│   ├── pages.js        ← الصفحات الـ 11
│   └── app.js          ← المحرك اللي بيربط كل حاجة
└── images/
    ├── oats.jpg
    ├── chicken-bowl.jpg
    └── salmon.jpg
```

كل ملف جواه تعليقات بالعربي (السطور اللي بتبدأ بـ `//` أو `/* */`) بتشرح كل جزء. التعليقات دي المتصفح بيتجاهلها، فهي للقراية بس.

## 2. تشغيله على جهازك

1. نزّل **VS Code** من code.visualstudio.com.
2. من جوه VS Code افتح **Extensions** (المربعات على الشمال)، ودوّر على **Live Server** ونزّله.
3. فك الـ zip، واعمل **File > Open Folder** واختار فولدر `sfn-dashboard`.
4. دوس كليك يمين على `index.html` واختار **Open with Live Server**.
5. الصفحة هتفتح في المتصفح، وأي تعديل تحفظه (`Ctrl + S`) هيظهر لوحده.

> ليه Live Server ومش دبل كليك على الملف؟ لأن بعض المتصفحات بتمنع تحميل الملفات المرتبطة لما تفتح الصفحة كـ "ملف". Live Server بيشغّلها كأنها موقع حقيقي.

## 3. الربط بين الملفات

### إزاي index.html بيعرف باقي الملفات؟

جوه `index.html` فيه سطرين نوعين:

```html
<link rel="stylesheet" href="css/style.css">   ← بيجيب الشكل
<script src="js/data.js"></script>            ← بيجيب الكود
```

`href` و`src` هما "العنوان" بتاع الملف بالنسبة لمكان `index.html`. عشان كده لو غيّرت اسم فولدر أو ملف، لازم تغيّره هنا كمان.

### ليه ترتيب ملفات الـ JS مهم؟

المتصفح بيقرا الملفات بالترتيب. وكل ملف بيستخدم حاجات من اللي قبله:

| الملف | بيستخدم إيه من اللي قبله |
|---|---|
| `data.js` | ولا حاجة، ده الأساس |
| `components.js` | `L` و `ic` و `S` من data.js |
| `pages.js` | البيانات من data.js، و `kpi` و `head` و `mk` من components.js |
| `app.js` | كل اللي فات، وبيشغّل الصفحة |

لو بدّلت الترتيب، هتلاقي في الـ Console غلطة زي `L is not defined`.

### إزاي الصور بتظهر؟

في `data.js`، كل وصفة فيها `img:'images/oats.jpg'`. وفي `pages.js` بنعمل `<img src="${r.img}">`، فالمتصفح بيروح يجيب الصورة من فولدر `images`.

## 4. اللي بيحصل لما الصفحة تفتح (خطوة بخطوة)

1. المتصفح يقرا `index.html` ويلاقي 3 أماكن فاضية: `side` و `top` و `content`.
2. يحمّل الـ CSS، فالصفحة تاخد الألوان والتقسيم.
3. يحمّل ملفات الـ JS بالترتيب.
4. آخر جزء في `app.js` (اسمه Init) يشتغل:
   - `applyLang()` يظبط اللغة والاتجاه.
   - `renderTop()` يرسم الشريط اللي فوق.
   - `route()` يقرا اللينك، ويرسم الـ sidebar، ويعرض الـ skeleton، وبعد 450ms يرسم الصفحة.

## 5. اللي بيحصل لما تدوس على حاجة

### لما تدوس على لينك في الـ sidebar

```
تدوس "المتدربين"
  ← اللينك فوق يبقى  ...#trainees
  ← المتصفح يطلق حدث اسمه hashchange
  ← app.js سامع الحدث ده، فيشغّل route()
  ← route() تاخد "trainees" وتشغّل P.trainees() من pages.js
  ← النتيجة (HTML) تتحط جوه content
```

### لما تكتب في البحث أو تدوس tab

```
تكتب "سارة"
  ← oninput تنادي setDashQ('سارة')  (في app.js)
  ← setDashQ تكتب S.dash.q = 'سارة'
  ← وبعدين render()
  ← P.dashboard() بتفلتر TRAINEES وتطلع اللي اسمهم فيه "سارة" بس
  ← الجدول يترسم من جديد
```

دي أهم فكرة في المشروع كله، اسمها **State → Render**: متعدّلش الصفحة بإيدك، عدّل الـ State وارسم من جديد.

### لما تدوس EN

```
toggleLang()
  ← S.lang تبقى 'en'
  ← applyLang() تخلّي dir="ltr"، فالـ CSS يقلب الصفحة لوحده
  ← كل حاجة تترسم من جديد، وكل L('عربي','English') ترجّع الإنجليزي
```

## 6. شرح كل ملف

### css/style.css

| الجزء | بيعمل إيه |
|---|---|
| الألوان (`:root`) | الـ palette: رمادي فاتح للخلفية، أبيض للكروت، أسود، أخضر فسفوري `#B6FF00` |
| الوضع الغامق | نفس المتغيرات بقيم غامقة، بتشتغل لما `data-theme="dark"` |
| `.side` | الـ sidebar، دايماً أسود |
| `.app` | تقسيم الشاشة لعمودين بالـ grid |
| `.card`, `.kpi`, `.chip`, `.btn` | أشكال القطع المختلفة |
| `.skel`, `.empty`, `.error` | حالات Loading و Empty و Error |
| `@media` | قواعد الموبايل والتابلت |

**أهم معلومة:** عشان تغيّر لون، غيّره في `:root` بس.

### js/data.js

- **`S`**: الـ State. كل حاجة متغيرة في الصفحة متسجلة هنا.
- **`L(ar, en)`**: بترجّع النص حسب اللغة. مثال: `L('المتدربين','Trainees')`.
- **`T(obj)`**: نفس الفكرة للبيانات المكتوبة `{ar:'...', en:'...'}`.
- **`ic('name')`**: بتعمل أيقونة. أسماء الأيقونات من fonts.google.com/icons.
- **القوايم**: `COACHES` و `TRAINEES` و `PROGRAMS` و `DIETS` و `SUBS` و `RECIPES` و `NAV`.

**الربط بين البيانات:** المتدرب فيه `coach:'C-101'`، والـ function `coachOf('C-101')` بتدوّر في `COACHES` وترجّع المدرب. ده بالظبط زي الـ foreign key في قاعدة البيانات.

### js/components.js

كل function بترجّع HTML جاهز:

| الـ function | بترسم إيه |
|---|---|
| `kpi({...})` | كارت رقم |
| `head(...)` | عنوان الصفحة والزراير |
| `btn(icon, label, cls, onclick)` | زرار |
| `aiBanner(...)` | شريط توصية الـ AI |
| `tabs(...)` | الـ tabs |
| `pager(...)` | أرقام الصفحات |
| `emptyState(...)` | حالة مفيش نتايج |
| `mk(id, config)` | chart بمكتبة Chart.js |

### js/pages.js

`P` فيها 11 صفحة. كل صفحة بتعمل 3 حاجات:
1. تفلتر البيانات حسب الـ State.
2. ترجّع `head(...)` + كروت + المحتوى.
3. ترسم الـ charts جوه `setTimeout`، لأن الـ `<canvas>` لازم يتحط في الصفحة الأول.

**حاسبة السعرات** بمعادلة Mifflin-St Jeor:
- BMR = 10×الوزن + 6.25×الطول − 5×السن + 5 (للراجل) أو −161 (للست)
- السعرات اليومية = BMR × معامل النشاط ± الهدف (تنشيف −500، تضخيم +300)

### js/app.js

| الـ function | دورها |
|---|---|
| `renderSide()` | ترسم القايمة الجانبية |
| `renderTop()` | ترسم الشريط اللي فوق |
| `render()` | ترسم الصفحة الحالية، ولو حصل خطأ تعرض حالة Error |
| `route()` | الـ Router |
| `toggleLang()` | زرار اللغة |
| `toggleTheme()` | زرار المظهر |
| `setDashTab`, `setTrQ`, ... | الـ Handlers: تغيّر الـ State وترسم |

## 7. تعديلات هتحتاجها كتير

**تضيف متدرب:** في `data.js` انسخ سطر من `TRAINEES` وغيّر بياناته.

**تغيّر لون:** في `style.css` غيّر القيمة في `:root`.

**تضيف صفحة جديدة:**
1. في `data.js` ضيف للـ `NAV`:
   `{id:'water',ic:'water_drop',t:{ar:'المياه',en:'Water'}},`
2. في `pages.js` ضيف:
   `P.water=()=>head([L('الرئيسية','Home')],L('المياه','Water'),L('وصف','Description'),'');`
3. خلاص، اللينك والـ router هيشتغلوا لوحدهم.

**تضيف نص جديد:** اكتبه دايماً كده `L('عربي','English')` عشان يترجم مع الزرار.

## 8. لو حاجة مش شغالة

اضغط `F12` في المتصفح وافتح **Console**. أي غلطة هتظهر بالأحمر ومعاها اسم الملف ورقم السطر.

| الغلطة | السبب الغالب |
|---|---|
| `X is not defined` | ترتيب ملفات الـ JS غلط، أو اسم مكتوب غلط |
| الصفحة من غير ألوان | مسار `css/style.css` غلط |
| الصور مش ظاهرة | مسار الصورة أو اسمها غلط (حروف كبيرة وصغيرة بتفرق) |
| الـ charts مش ظاهرة | مفيش نت، فمكتبة Chart.js محمّلتش |

## 9. رفعه على GitHub Pages (عشان تاخد preview link)

1. اعمل حساب على github.com.
2. **New repository**، سمّيه مثلاً `sfn-dashboard`، وخليه **Public**.
3. **Add file > Upload files**، واسحب كل محتوى الفولدر (مش الفولدر نفسه، اللي جواه)، ودوس **Commit changes**.
4. **Settings > Pages**، وفي **Branch** اختار `main` و `/ (root)` ودوس **Save**.
5. استنى دقيقة أو اتنين، وهيظهرلك لينك زي:
   `https://اسمك.github.io/sfn-dashboard/`

ده الـ preview link اللي تحطه على Jira.

## 10. قاموس صغير

| الكلمة | معناها |
|---|---|
| **HTML** | هيكل الصفحة |
| **CSS** | شكل الصفحة |
| **JavaScript (JS)** | تصرفات الصفحة |
| **function** | مجموعة أوامر ليها اسم، بتناديها فتشتغل |
| **State** | الوضع الحالي للصفحة (اللغة، البحث، الـ tab) |
| **Render** | رسم الصفحة من جديد حسب الـ State |
| **Router** | الجزء اللي بيقرر أنهي صفحة تظهر حسب اللينك |
| **Component** | قطعة UI بتتكرر (كارت، زرار، جدول) |
| **RTL / LTR** | اتجاه الكتابة: يمين لشمال / شمال ليمين |
| **Responsive** | الصفحة بتظبط نفسها على أي مقاس شاشة |
| **Fake / Mock data** | بيانات وهمية لحد ما الـ backend يجهز |
| **Console** | المكان في المتصفح (F12) اللي بتظهر فيه الغلطات |
